## Findings

### FINDING-1: concierge_intake IA/Schema Mismatch (HIGH)

**Artifact:** combine-config/document_types/concierge_intake/releases/1.0.0/package.yaml
**Authority:** ADR-054, output.schema.json

The concierge_intake IA declares binds to fields that do not exist in the schema:
- `summary` (IA expects nested object) — schema has `captured_intent` (string) and `conversation_summary` (string)
- `open_gaps` (IA expects nested object with questions/missing_context/assumptions_made) — schema has `known_unknowns` (string array)
- `outcome` (IA expects nested object with status/rationale/next_action) — schema has `gate_outcome` (string enum), `routing_rationale` (string), `ready_for` (string)

Also: `project_type` is a string enum in schema but IA treats as nested-object; `constraints` is a string array but IA treats as nested-object.

**Fix:** Reconcile IA binds with actual schema structure. Either update IA to match schema's flat field names, or update schema to match the nested structure the handler actually produces.

### FINDING-2: Unsupported render_as Type `string-list` (MEDIUM)

**Artifact:** IABlockRenderer.jsx
**Authority:** concierge_intake package.yaml

`string-list` is used in concierge_intake IA but has no case in IABlockRenderer's switch statement. Falls through to paragraph, which renders arrays as JSON strings.

**Fix:** Add `string-list` case to IABlockRenderer, or replace with `list` in the concierge_intake IA.

### FINDING-3: work_statement Has No IA (MEDIUM)

**Artifact:** combine-config/document_types/work_statement/releases/1.1.0/package.yaml
**Authority:** ADR-054

Work Statements are content-rich operator-facing documents (16 schema fields including procedure, verification_criteria, prohibited_actions, allowed_paths) with no IA declarations. Cannot use IA-driven rendering.

**Fix:** Author IA sections for work_statement v1.1.0 covering at minimum: objective, scope_in, scope_out, procedure, verification_criteria, prohibited_actions, allowed_paths, governance_pins.

### FINDING-4: IA Gate Depth Limitation (LOW)

**Artifact:** app/domain/services/ia_gate.py
**Authority:** ADR-054

IA gate only validates top-level bind path presence. Does not check:
- Sub-field presence within nested-object binds
- render_as / data-type compatibility (e.g., table bind pointing at a string)
- Array element structure within card-list binds

**Fix:** Consider deeper validation in a future version of the gate.
