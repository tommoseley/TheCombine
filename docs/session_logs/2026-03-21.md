## Decisions Made
- SQLAlchemy JSONB mutation tracking is the root cause of MSTC-001 TA generation failure
- TA prompt needs component registry authority rules (same pattern as WP/WS governance supplements)
- Pipeline rewind is a first-class Combine capability (ADR-063)
- Canonical stage ordering: CI → PD → TA → IP → WP → WS (PGC is cross-cutting, not a stage)
- Linear dependency model for MVP: rewind at N invalidates N and all later stages
- Three-status model: current / stale / superseded (not six)
- Prompt/schema changes do NOT trigger automatic rewind
- Stabilization revocation on upstream rewind (per-version, not per-document)
- Keep `is_latest` as computed/maintained flag for backward compatibility
- Document versioning is a contained migration, not a model refactor (Do No Harm audit finding)
