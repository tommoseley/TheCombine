## Decisions Made
- Pipeline stage order is CI → PD → IP → TA → WP → WS (IP before TA, not after)
- Rewind button goes in document header (FullDocumentViewer + ConfigDrivenDocViewer), not PipelineRail
- QA gate distinguishes "audit incomplete" from "document noncompliant" — missing authority context is advisory, not hard fail
- PGC answers are project authority, not execution state (ADR-064)
- Authority is path-aware: resolved against current lineage path
- Artifact rewind does NOT automatically demote authority
- "superseded" = replaced on active path; "historical" = path abandoned
- lineage_event_id renamed to lineage_path_id (represents path membership, not single event)
