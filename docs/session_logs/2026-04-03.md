## Decisions Made
- ADR-069 drafted and accepted: rewind becomes the correction gate for operator-injected binding constraints
- Single-field design: the rewind reason IS the correction brief — one field, dual-written to lineage event (audit) + authority record (binding for regeneration)
- Pre-population: on subsequent rewinds, the reason textarea is pre-populated from the authority store
- Every rewind creates an authority record (not optional) — supersession ensures one current correction per (project, stage)
- Corrections are editable before regeneration via PATCH endpoint
- ReadyState shows inline correction brief with "Restart Production" button when stage was rewound
- Timeline viewer redesigned as git-style graph with SVG lane lines, branch curves, collapsible branches
- WSs nested under owning WPs in timeline using parent_wp_id
- Rewind button styled red to match Confirm Rewind
